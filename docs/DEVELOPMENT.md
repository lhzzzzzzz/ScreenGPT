# 开发与人工验收

ScreenGPT 是 Swift Package，使用 SwiftUI 和 AppKit 构建 macOS 14 或更新版本的菜单栏应用。`ScreenGPTCore` 保存与界面无关的逻辑；`ScreenGPT` 可执行目标包含界面、屏幕截取、账号连接和网络请求。`Resources/AppIcon.svg` 提供可编辑的矢量图标素材；实际打包的 PNG 和 `AppIcon.icns` 由 `scripts/generate-icon.swift` 绘制生成，修改图标时请同步调整这两份设计。

## 构建

安装包含 Swift 6 的 Xcode 16 或更新版本，或对应 Command Line Tools 后，在项目根目录运行：

```sh
swift test
./scripts/build.sh
```

`build.sh` 默认生成 `arm64` 和 `x86_64` 通用版本，并写入 `dist/ScreenGPT.app`。仅需本机架构时，可设 `ARCHS=arm64` 或 `ARCHS=x86_64`。打包为可拖入“应用程序”的 DMG 和 ZIP：

```sh
./scripts/package.sh
```

首次启动应用需要在“系统设置 → 隐私与安全性 → 屏幕录制”授予权限。开发阶段的包使用 ad hoc 签名，因此系统会显示未验证开发者提示。请仅在信任构建来源时绕过该提示；公众发布应使用 Developer ID 签名和公证。

## 人工验收清单

以下流程需要在支持的 Mac 上手动验收。测试未完成前，不要声称相关 UI、权限、账号或联网流程已通过验证。

- [ ] macOS 14 或更新版本可启动应用；菜单栏图标、设置窗口、退出菜单可用。
- [ ] 首次启动可引导用户授予屏幕录制权限；拒绝权限后给出清楚说明。
- [ ] 默认 **⌘⇧D** 可唤出截屏框选；快捷键可修改，Escape 可关闭。
- [ ] 单屏与多屏都能分别显示静止画面，选择区、暗度调整和浮窗位置正确；更改显示器布局后可继续使用。
- [ ] 框选后“做题”和“翻译”分别发起请求；结果逐步显示，可复制、取消、重新框选和保存。
- [ ] 已有译文时修改原文、目标语言或交换语言，自动重新翻译当前选区并保留未发送草稿；快速切换不会让旧回答覆盖新选择。首次翻译前修改语言只更新选项。
- [ ] 在“通用”中切换简体中文与英文后，菜单和相关界面文字立即更新；重启后语言选择保持。
- [ ] 框选工具栏的“提问”按钮只在点击后展开输入框；⌘Return 发送，Return 插入换行。
- [ ] 做题和翻译结果可继续追问；追问继续使用首次请求的裁剪图、模型与思考强度。重新框选、调整选区大小或位置、结束选区后，对话按预期结束或更新。
- [ ] 做题、翻译、提问的模型配置分别保存；提问初始采用做题配置，追问保留本轮首次请求的模型与思考强度。
- [ ] 复制或保存一轮对话时，转录内容以单条记录呈现，且只包含用户可见的问题与回答。
- [ ] 做题和翻译的模型与思考强度分别保存；重启后保持选择，请求使用对应任务的配置。模型不支持的档位不发送。
- [ ] 从账号页开始框选且屏幕权限未生效时，切回通用页并明确显示权限说明；连续按快捷键不会启动两次截屏。
- [ ] 更新应用后，钥匙串要求重新确认时设置窗口仍可操作；点击“解锁已保存账号”后，由用户完成 macOS 确认并恢复模型列表。
- [ ] 仅在明确选择任务后上传裁剪图；登录和授权由默认浏览器完成，权限不足时呈现可理解的提示。
- [ ] 未启用自动保存时回答不会进入历史；手动保存、删除、重启后读取历史符合预期。
- [ ] Apple Silicon 和 Intel Mac 上的包分别可启动，DMG 拖放安装流程正常。

CI 会执行 `swift test` 并生成通用 `.app`、`.dmg` 和 `.zip` 构建产物；CI 成功不等于上面的真实 UI、OAuth、网络或 Gatekeeper 流程已通过验收。
