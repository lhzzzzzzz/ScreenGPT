# v0.1.1 验证记录

验证日期：2026-10-06（澳大利亚墨尔本时间）

当前版本可用于安装测试，尚未完成全部发布验收。

## 本次更新

- 做题和翻译分别保存模型及思考强度；旧版单一模型迁移到两项初始值。
- 可选择自动、轻度、中度、高度、极高；以服务端能力字段为准，缺少字段时仅为官方文档已确认的精确模型名提供档位。未知模型仅使用默认强度。
- 每次请求固定使用该任务开始时的配置；不发送不受支持的思考档位，所选模型不可用时明确提示。
- 屏幕权限未生效时，框选入口会打开通用页并显示具体原因；提示也会保留在其他设置页顶部。
- 快速重复触发快捷键时取消待启动的截屏，避免同时创建多个截屏任务。
- 钥匙串读取移到后台；需要系统确认时仍可操作设置窗口，未读取成功前禁止覆盖旧账号。

## 已完成

- 43 项 Swift Testing 测试通过，包括两套配置独立保存、旧设置迁移、能力字段解码、档位校验，以及原有布局、身份验证和流式响应测试。
- 已生成 `arm64` + `x86_64` 通用应用及 DMG、ZIP。
- `/Applications/ScreenGPT.app` 启动成功，版本为 0.1.1；安装版可执行文件与打包产物 SHA-256 相同。ad hoc 签名检查和 DMG 校验通过。
- 安装版账号页显示独立的做题、翻译模型及思考强度控件；已在真实模型列表中选择做题 GPT-6-Astra / 高度、翻译 GPT-5.6-Luna / 轻度，两组互不影响。
- 完全退出后重开，账号和模型列表自动恢复，两组模型及思考强度保持上述选择。
- 从账号页点击“开始框选”，在录屏权限未生效时正确切换到通用页，并在顶部显示权限原因和重启建议。
- 更新后由用户完成 macOS 钥匙串确认，已恢复套餐授权和真实模型列表。未查看、记录或填写系统凭据提示中的私密内容。

## 前版已验证的界面行为

- 设置页切换、暗度滑块在退出重开后保持设置（恢复为 35%）。
- 内置预览的小选区、大选区、英语到中文示例翻译与解题、Escape 关闭。
- 小选区工具栏靠近选区，答案显示在选区外；大选区外部空间不足时，答案显示在选区内。
- 拖动浮窗标题栏可移动回答；“交换语言”可切换本次翻译方向。

预览使用合成内容和固定示例答案，不截取屏幕，也不调用模型。这些预览结果不能证明真实截图和模型请求可用。
