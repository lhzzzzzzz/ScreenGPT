# 隐私说明

ScreenGPT 不提供遥测或分析功能。应用会在本机截取各个显示器的画面，供你框选使用；完整画面只在内存中处理。你发送做题、翻译或追问时，请求会包含当前裁剪图、你的问题以及本轮此前的对话内容。已有翻译时切换翻译语言，也会自动对同一裁剪图发起新的翻译请求。后续对话会继续使用同一裁剪区域，直到你重新框选、调整选区或结束选区。登录、列出可用模型和刷新凭据也会按你的操作连接 OpenAI 服务。

## 发送给 OpenAI 的内容

- OAuth 登录通过 `auth.openai.com` 完成，模型列表从 `api.openai.com/v1/models` 获取。
- 你发送做题、翻译或追问时，当前裁剪图片、用户问题和此前对话内容会发送到 `api.openai.com/v1/responses`。追问上下文包括之前的输出项目，以便模型延续本轮对话。未选中的全屏画面不会加入此请求。
- 请求设置 `store: false` 并使用流式返回；上下文由应用随请求提供，而不是依靠服务端保存的响应状态。这只描述应用发出的 API 参数，**不代表 OpenAI 对数据零保留，也不替代 OpenAI 的服务条款、隐私政策或账号数据控制**。OpenAI 对请求的处理和保留取决于其现行政策、服务及你的账号设置。
- 登录和授权会让 OpenAI 接收完成 OAuth 所需的信息。你可以在 ChatGPT 中管理连接的应用及用量。

## 本机保存

登录凭据保存在 macOS 钥匙串中。ScreenGPT 的偏好设置保存在 macOS 用户偏好中。历史记录默认不会自动保存；你可以手动保存对话，也可以在设置中开启自动保存。每条保存记录包含本轮可见的问题与回答，以及裁剪图片和少量任务信息；不会把未显示给用户的模型输出项目加入历史记录。复制会得到本轮可见问答的 Markdown 文本，不创建历史记录。保存时整轮对话作为一条记录写入：

`~/Library/Application Support/ScreenGPT/History`

历史记录以 JSON 文件保存在本机，并设置受限的文件权限；这些文件没有由 ScreenGPT 单独加密。你可以在“已保存”页面逐条删除，或自行移除上述文件夹。删除本机副本不会撤回已经发送给 OpenAI 的请求或删除服务端可能保留的数据。

## 权限与控制

macOS 屏幕录制权限用于在本机显示可供框选的屏幕画面。你可以在系统设置中撤销该权限。账号退出会清除 ScreenGPT 本机保存的访问凭据，并尝试向 OpenAI 撤销刷新凭据；如果远端撤销未能确认，请到 ChatGPT 设置中检查并移除此连接。退出账号不会删除已经保存的本地历史记录。

ScreenGPT 是独立开源应用，与 OpenAI 无隶属关系。隐私说明针对当前源码行为；OpenAI 服务端的数据处理由 OpenAI 的现行政策决定。
