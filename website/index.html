第一次使用，从这里开始。

安装后，完成屏幕录制授权和 ChatGPT 登录。

  1. 拖入“应用程序”

    打开下载的 DMG，把 ScreenGPT 拖到“应用程序”文件夹，再启动应用。

  2. 允许屏幕录制

    在“系统设置 → 隐私与安全性 → 屏幕录制”中允许 ScreenGPT。授权后按提示重新检测或重启应用。

  3. 连接你的 ChatGPT 账号

    在“ChatGPT 账号”中点击“Continue with ChatGPT”，通过浏览器完成授权。随后按 ⌘ ⇧ D 开始框选。

测试版安装提示

提示“无法验证开发者”？

当前版本采用临时签名，尚未经过 Apple 公证。确认安装包来自本项目、且你信任其来源后：

  1. 先尝试打开一次 ScreenGPT。
  2. 进入“系统设置 → 隐私与安全性”。
  3. 找到 ScreenGPT 的提示，点击“仍要打开”，按系统提示确认。

只为此应用确认例外，保留系统安全检查。受管理的 Mac 可能无法进行此操作。

查看 Apple 官方说明 ↗

下载前，你可能还想知道。

ScreenGPT 免费吗？

应用免费开源，采用 MIT 许可证。使用模型需要你自己的 ChatGPT 账号；套餐费用、模型权限和使用额度由 OpenAI 决定，ScreenGPT 不提供额外模型额度。

需要 API key 吗？所有 ChatGPT 账号都能用吗？

不需要 API key 或安装 Codex CLI，通过浏览器登录并授权即可。是否能使用所选模型及套餐额度，取决于 OpenAI 对你的账号、工作区和模型的授权，无法保证所有账号都可用。

会把整个屏幕发送出去吗？

只有你明确点击“翻译”或“做题”后，应用才会把选中的裁剪区域发送给模型。完整屏幕画面用于本机显示和框选，不会作为请求内容发送。登录凭据保存在 macOS 钥匙串中。

自动保存默认关闭。手动或自动保存的记录会包含截图和回答，保存在本机。阅读完整隐私说明。

支持哪些 Mac？遇到问题怎么办？

需要 macOS 14 或更新版本。安装包包含 Apple 芯片与 Intel 架构，Intel 实机尚未验证。当前为早期测试版，多显示器等场景仍需进一步验证。
